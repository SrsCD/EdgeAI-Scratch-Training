## Short continuation plan, gated

The checkpoint [best.pt](../runs/scratch_yolo11n_stage3c_experimental_b16/weights/best.pt) exists, has SHA-256 `1bb3228630eb609b71cfb773ba67212c7641e0d477bdc4b79883ecd747c28a24`, and its [provenance](../runs/scratch_yolo11n_stage3c_experimental_b16/stage4a_provenance.json) records architecture-YAML **random initialization**, `pretrained=false`, `resume=false`, 12 completed epochs and best checkpoint at epoch 12. It is suitable as a *technical* starting point for continuation, with `resume=False` so the new experiment has its own epoch count and output. It is **not yet suitable for a meaningful Stage 5C data experiment**: no correction is accepted, only two training images are queued for manual review, many source omissions remain unresolved, and independent CCTV validation is absent.

After reviewed corrections and an independent CCTV scene are available, use a distinct `runs/scratch_yolo11n_stage5c_continuation_v1` output directory and a frozen Stage 5C data manifest. Proposed bounded settings: checkpoint above as `model`, `pretrained=False`, `resume=False`, **8 epochs**, batch **8** on RTX 3050 6 GB, `imgsz=640`, `workers=0`, `amp=False`, `seed=42`, deterministic mode, validation each epoch on the unchanged Stage 3C validation split, patience 4, `exist_ok=False`. Select `best.pt` by that validation fitness only; assess the separate CCTV scene once after selection, with no test-set tuning. Do not restart from random weights or use COCO-pretrained weights. Preserve Stage 4B reports, metrics and confusion matrices unchanged.

Stage 4A recorded **2,078.32 seconds for 12 completed batch-16 epochs**, about **173 seconds or 2.9 minutes per epoch** on this RTX 3050. Eight batch-16-equivalent epochs would be about 23 minutes. Batch 8 has not been benchmarked; allow roughly **30–45 minutes plus setup and validation overhead** for eight epochs, then verify against a short measured smoke run once the data gate passes. Stage 4A's batch-16 training log used about 4.5 GB GPU memory; batch 8 is a conservative 6 GB choice, not a guarantee. The corrected-set size and data loading can change timing.
