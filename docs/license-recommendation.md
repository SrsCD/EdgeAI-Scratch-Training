# License recommendation for repository review

The architecture YAML derives from the Ultralytics YOLO11 YAML. [`models/architecture_provenance.json`](../models/architecture_provenance.json) records its upstream version and AGPL-3.0 notice. Ultralytics is also a runtime dependency. [Ultralytics describes its models and software as AGPL-3.0 or enterprise licensed](https://docs.ultralytics.com/help/contributing/). Before publication, review the upstream obligations for this project's source and model distribution; AGPL-3.0 is the conservative code-license recommendation if using the open-source route. Obtain legal or organizational review where needed, then add a `LICENSE` file with the chosen terms.

No project license has been selected here. [GitHub explains that a public repository without a license is viewable, but does not grant general reuse rights](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository). A code license would **not** cover third-party dataset images, annotations, screenshots, source archives, or webcam evidence. Several contributing datasets have publisher-level Creative Commons or public-domain claims, while individual underlying image rights remain unresolved. Keep those assets out of the repository until rights and attribution are documented.
